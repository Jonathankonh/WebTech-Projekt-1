3. Lernfortschritt - Nutzer kann Artikel als gelernt markieren 
4. Live ETF Suche - Echtzeit Abfrage von ETF-Daten über REST API
5. Kosten-Analyse - TER Rechner Tool, welches die Kosten über einen Zeitraum berechnet
6. Persönliche Watchlist - speichert interessante ETFs in einer Liste
7. Dashboard: Zentrale Übersicht über Lernfortschritt, zuletzt gesehene ETFs und co
